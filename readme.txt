**version: 1.2.1**

do `pip install -r requirements.txt` to get the required packages

CTRL + E -- Edit Settings
CTRL + K -- Kill App
CTRL + F -- Fullscreen
Win/Cmd + Shift + W -- Hide/Unhide/Call-on-Top

go to settings to link your spotify account for music data and playback control

change your "input device" to system/speakers (recommended), use mic ONLY if the sound is external

available FPS -- 60/45/30, low detail mode available
